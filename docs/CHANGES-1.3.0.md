# 1.3.0 开发汇总（相对 v1.2.3）

汇总日期：2026-11-24。软件版本为 1.3.0 发布候选，发布源码已切换 release 标记并随 PR #19 合入 main；`v1.3.0` 标签固定于 `c3963b8`。标签与候选检查不代表已公开发布。

## 来源

汇总分支为 `integration/v1.3.0`，纳入 `tooling/github-app-identity` 的功能与修复、`main` 的分发维护、`tooling/ci-candidate-promotion` 的候选产物导入，以及 `fix/ci-remote-scan-result` 的扫描测试修正。后者的主要断言此前已存在于功能分支，本次保留，并将人类输出断言同步为默认英文。

另纳入本机已验证的默认英文改动。此前误以 main 为基础的 1.3.0 / 1.3.1 修改保留在 stash，未纳入本分支；本地 dist 产物和用户配置不入库。

## 功能与体验

- 中英文 CLI / TUI、持久语言偏好、`domino language en/zh`、单次 `--lang` 覆盖和远端语言传递；无已保存偏好时默认英文。
- 安装、状态、配置、扫描、shell 和诊断输出统一间距与字段对齐，默认聚焦结果，详细说明放入 `--verbose`；保留错误、部分完成及恢复信息。
- `domino doctor` 与 TUI 诊断入口，对照原生 / 代理 HTTPS、DNS、hosts 和路由；区分未检测与失败。
- 配置列表展示订阅用量、剩余、到期及缓存新鲜度，支持显式刷新套餐缓存。
- 扫描提示明确通过 catch 菜单或 `--source PATH` 选择外部配置；终端策略关闭或部分接管时展示实际保留的代理地址并隐藏凭据。

## 平台与可靠性

- macOS 使用具独立应用身份的原生启动器运行原 Mihomo，配套图标、资源打包、备份与失败恢复，并等待 LaunchAgent 卸载完成后重启。
- 使用目标系统 DNS 和 hosts 支持公司内网 DIRECT 访问，不接管系统 DNS；旧缓存及离线配置沿用修正。
- macOS 默认接入 Zsh，Ubuntu / Linux 默认接入 Bash，保留另一种 shell 的既有设置；完善安装补全和父 shell 同步。
- CLI 状态区分开发构建指纹、运行时快照与内核版本；完善资源离线交付、SSH 大载荷传输及新旧 CLI 同步。

## 构建与分发维护

- 统一本机 PyPI、Homebrew 与签名 APT 分发；复用已有发行产物，维护者要求发布凭据以 TXT 和 GPG 文件集中放在 OneDrive `oetree/domino/tokens`；完善 HTTPS、签名校验和幂等发布。
- 统一 AGENTS.md 和审批约定；2026-11-24 取消必须由专用 GitHub App 推送和创建 PR 的限制，允许使用本机已登录账号，继续保留人工审批和分支保护。
- 增加经过摘要校验的自托管 CI 候选产物导入，补充分发工具测试与文档；已发布版本补发渠道时始终复用官方原始字节，候选产物只能用于一致性核对，差异时拒绝继续。

## 验证边界

历史记录中 macOS 公司现场技术及浏览器验收已完成；最新源码的 Ubuntu 真机验收仍待完成。历史结果不代表本次汇总已重跑完整回归。本次实际检查见交付说明；已有固定发布候选标签，尚未正式公开发布 1.3.0。工具与现有 1.2.3 渠道的维护另见[分发维护记录](DISTRIBUTION.md#分发维护记录)。
